El nuevo paquete dedicado al robot real debe concentrar todo lo 
necesario para arrancar el hardware y conectarlo con el stack de 
navegación.

Según la arquitectura del equipo, este paquete puede incluir o 
integrar launch files y nodos para:

    micro-ROS agent
    LiDAR real
    Controller del robot
    Odometría
    Publicación de joint_states
    Transformaciones estáticas necesarias
    Configuraciones reales de Nav2 y SLAM
    Cualquier otro nodo indispensable para la operación del Puzzlebot físico

Importante: la expectativa es que estas piezas no se sigan lanzando 
manualmente una por una. Deben quedar integradas en un flujo ordenado 
de lanzamiento dentro de su propio paquete.
